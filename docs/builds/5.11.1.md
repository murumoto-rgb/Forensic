* **Summary:** Hot-fix for "Sync now does nothing visible" on Build #5.10.1. Root cause: `PhotoSyncer.syncProject` iterated photos before plans. On a fresh install (TestFlight or sideload) the per-device `UploadedFileTracker` is empty, so every one of the 799 photos in the user's Manandhar project gets a full `getUploadUrl → R2 PUT → commitUpload` round-trip even though the files already exist in R2. That can take 15-40 minutes before the plan loop is reached. Plans are 1-5 per project; running them first means the web canvas backgrounds appear within seconds while the photo backfill continues in parallel later. Three-line code change.
