## Build 5.24.1

* **Date:** 2026-06-02
* **PR:** [#54](https://github.com/murumoto-rgb/Forensic/pull/54)
* **Branch:** claude/distress-place-fix
* **Merge SHA:** 0994f58
* **Summary:** Fix for Build #5.23.1: distress kind picker appeared but clicks on the canvas didn't place a mark. Root cause was an over-strict `e.target === stage` guard in `handleStageClick` and `handleStrokeStart` on FloorPlanCanvas. Konva clicks bubble up from the rendered children, so a click on the plan area has `e.target` set to the KonvaImage (the plan background) — the guard mistakenly treated this as "click came from a pin/glyph" and bailed. Fix: drop the guard from the Stage handlers; instead, stop the bubble at the source for clicks/mousedowns on `PhotoPin` and `DistressGlyph`. This preserves the original intent (clicks on pins/glyphs don't place a new mark) using the correct mechanism. Web-only; no iOS, server, shared, or schema change.
