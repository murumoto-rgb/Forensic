* **Summary:** Phase 4 kick-off — server-side AI-tagging proxy. New endpoint `POST /v1/ai/tag-photo` (server-only): client sends `projectId`, `photoId`, `model` (`claude-sonnet-4-6` or `claude-haiku-4-5`), `systemPrompt`, `userText`; server validates ownership, fetches the full-resolution photo bytes from R2, calls Anthropic's Messages API with `system + (image + userText)`, and returns the concatenated text response plus token-usage metrics. Parsing into iOS's `AIPhotoAnalysis` is deliberately NOT done server-side — iOS already has a mature parser, the server is a thin pass-through to keep credential surface small. New `getObjectBytes(objectKey)` helper in `r2.ts`. New `ANTHROPIC_API_KEY` env var is OPTIONAL — server boots cleanly without it; the endpoint returns 503 "AI tagging not configured" until it's set in Render, so the deploy doesn't have to be sequenced with the secret. Shared types added: `AITagPhotoModel`, `AITagPhotoRequest`, `AITagPhotoResponse`. iOS + web integration lands in follow-up PRs. Server + shared; no iOS, web, or schema change; no `manifestSchemaVersion` bump.
