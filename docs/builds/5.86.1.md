* **Summary:** Three-level tag-selection picker on web — closes Path P follow-on #6. New `ProjectTagSelectionPicker.tsx` mirrors iOS `ProjectTagSelectionSheet`: a modal with three columns (contexts → primaries → secondaries). Contexts are multi-select; primaries are grouped by their parent context and scoped to selected contexts only; the secondaries column reads the currently-focused primary and shows its secondaries with every entry on-by-default (deselecting writes into `deselectedSecondariesByPrimary`). Toggling a primary off drops its deselection entries so they don't strand. Toggling a context off drops every primary entry from that context. Local draft state keeps partial edits out of the saved manifest until the user clicks "Save selection"; "Cancel" discards. An "Edit selection…" button replaces the read-only-summary block in `ProjectAIConfig.tsx`'s tag-selection section; the existing counts summary stays. Loads the canonical library at mount via the existing `api.getTagLibraryConfig()` (no new endpoints); shows a friendly "open the iOS app once" message if the library hasn't been seeded. Three-column grid on `lg:` viewports collapses to stacked sections on narrow. No schema change, no shared API change, no iOS change. No `manifestSchemaVersion` bump.
