* **Summary:** Fix the "Could not find Chrome (ver. 149.0.7827.22)" runtime error that surfaced on the deployed server after #5.65.1 — first stop of the Path-C parity work the user committed to (8 PRs total; this is #1/8). Root cause: pnpm 9.12 disables lifecycle scripts of dependencies by default, so `puppeteer`'s postinstall (which downloads the Chromium binary) never ran during `pnpm install --frozen-lockfile` on Render. Two complementary fixes: (1) root `package.json` gets a `pnpm.onlyBuiltDependencies: ["puppeteer"]` whitelist so the postinstall runs on every fresh install (local + CI + Render); (2) `render.yaml` `buildCommand` appends an explicit `pnpm --filter @forensic/server exec puppeteer browsers install chrome` step as a belt-and-suspenders guarantee — ~1 sec when the binary is cached in `PUPPETEER_CACHE_DIR`, ~30 sec on a cold cache. With both in place, every Render deploy lands with Chromium present at the path Puppeteer's launcher looks for. Config-only change; no code touched, no schema change, no shared/iOS/web behavior change.
