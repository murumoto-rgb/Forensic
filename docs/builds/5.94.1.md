* **Summary:** Floor plan calibration sheet on web — replaces the placeholder-calibration shortcut Build #5.90.1 shipped with. New `FloorPlanCalibrationSheet.tsx` is a Konva-based full-viewport modal that walks the user through three crosshair placements (Origin → Point A → Point B), accepts the real-world A↔B distance in feet, optionally a north heading and label, then computes `pixelsPerFoot = dist(A,B) / feet`. Pan via the ✋ tool, scroll-wheel zooms around the cursor, and a 2.5× magnifier loupe follows the cursor for pixel-precise placement (rendered as a circular `<canvas>` overlay drawn from the natural image's clipped region — cheaper than spinning up a second Konva stage on every move). Tool buttons auto-advance Origin → A → B as the user places each. The "+ Add plan" affordance in `FloorPlanManager.tsx` now stages the picked File into `pendingFile` state instead of uploading immediately; the calibration sheet opens with that file, and the upload + manifest write fire only when the user clicks Save. Cancel discards the file entirely. Re-calibrating an existing plan still happens on iOS (the canvas-edit UI lives there); web's flow is add-only. New `CalibrationResult` interface carries the seven fields the FloorPlan needs — origin, A, B, feet, pixels/ft, north, label. Parity matrix updated: "Import floor plan" row now reads "calibration #5.94.1"; new "Calibrate plan" row added showing ✅ on add only. No schema change, no shared API change, no iOS change. No `manifestSchemaVersion` bump.
