## Build 5.37.1

* **Date:** 2026-06-04
* **PR:** [#67](https://github.com/murumoto-rgb/Forensic/pull/67)
* **Branch:** claude/web-retag-with-ai
* **Merge SHA:** 91f2cc1
* **Summary:** Closes the Web "Re-tag with AI" parity gap with iOS — office staff can now re-run AI tagging on any photo from the floor-plan preview panel without touching the iPad. New button + AI-model picker (Sonnet / Haiku) in `PhotoPreviewPanel` (Build #5.37.1's `ReTagWithAIControl`) reads the team's `tagLibrary` + `aiRulesTemplate` from `/v1/config` (populated by the iOS push that landed in #5.36.1), compiles the project-scoped system prompt via the new shared `compilePrompt(...)`, forwards through the `/v1/ai/tag-photo` proxy from #5.32.1, parses the rawText via the new shared `parseAIPhotoAnalysis(...)`, and writes the resulting `AIPhotoAnalysis` back to the photo. Save lands through the same optimistic-concurrency PUT loop pin-drag uses. New `packages/shared/src/promptCompiler.ts` is a byte-for-byte TypeScript port of iOS's `PromptCompiler.swift` so the prompt the web ships is identical to what iOS would have sent for the same (rulesTemplate, tagLibrary, project) triple — same system preamble, vocabulary-triple format, "(primary alone)" placeholder behaviour, "none" sentinel filter, extras / notes block layout, and output-contract reinforcement. New `packages/shared/src/aiResponseParser.ts` mirrors iOS's `parseResult(fromText:)` — same code-fence stripping, brace-slice extraction, ClaudePayload field decode, and soft-failure semantics (returns an `AIPhotoAnalysis` with `parseFailed: true` rather than throwing). Web API client (`web/src/lib/api.ts`) gains `tagPhoto`, `getAppConfigBundle`, `getTagLibraryConfig`, `getAIRulesTemplateConfig`. `ReTagWithAIControl` surfaces clear status banners: a red "no tag library on the server yet" hint when the GET 404s, a red ApiError for upstream failures, a yellow "model output was unparseable" when the parse fails (analysis still persisted), and a green "Tagged" on success. No iOS, server, supabase migration, or `manifestSchemaVersion` change. Repair-retry on vocabulary rejections is intentionally not ported — iOS keeps it; web takes the model's first response and lets the engineer eyeball.
