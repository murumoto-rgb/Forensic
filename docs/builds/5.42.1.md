* **Summary:** Sprint C2 of the AI-tagging completion plan — batch "Re-tag all with AI" runner on the project detail page. Second half of the command center; combined with #5.41.1 it makes web a real AI-tagging workstation. New `useBatchRetag` hook drives a bounded-concurrency task runner (default 3, user-adjustable 1-10 via slider) over every photo in the project: pre-flight compiles the system prompt once via `compilePrompt` (so "no tag selection" / "no library on server" fail fast before burning any Anthropic budget), then walks the candidates with a shared iterator across N worker promises so each worker grabs the next photo the moment it finishes the previous. Results land via the same `aiAnalysisToSuggestions` pipeline from #5.41.1 into `Photo.pendingSuggestions` — the engineer reviews per-photo on the floor-plan preview panel. Checkpoint save every 25 photos PUTs the manifest with the current revision so an interrupted run never loses more than that many photos' worth of work. Cancel button flips an internal flag; in-flight requests aren't aborted (proxy endpoint has no AbortController surface today) but no new tasks schedule and a final save flushes the tail. New `BatchRetagControl` + `BatchOptionsModal` + `BatchProgressPanel` components: button in the project header (disabled when project is empty or a run is in flight), modal with model picker / concurrency slider / skip-already-tagged checkbox, sticky bottom-left progress panel showing tagged / skipped / failed counts + a percent bar + a "show first failure" disclosure. `ProjectDetailPage` now tracks `revision` alongside `project`, mirrors both via refs so the hook reads the latest values at checkpoint time (defends against a concurrent pin drag racing the batch's PUT cadence). On done with zero failures, a green "Batch complete. Open each photo's preview panel to review pending suggestions." banner. Skip-already-tagged matches iOS's `skipAlreadyTagged` semantics — photos with at least one `tags` entry are passed over. Web-only PR. No iOS, server, shared schema, or `manifestSchemaVersion` change.
