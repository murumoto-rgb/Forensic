* **Summary:** **iOS edit-lock UI (Wave 4, item 1 — closes the Phase 5 iOS gap).** Server (#5.59.1) and web (#5.60.1, #5.120.1) have had the transient edit lock for weeks; iOS had zero lock code. Shipped now with a **deliberately advisory model, different from web's**: (1) **iOS never blocks editing on the lock.** Field capture must work offline and never wait on a network round-trip, and the server-side 3-way merge already makes concurrent edits lossless — so the lock on iOS is presence signaling, not a gate. (2) **Acquire-while-open:** opening a project workspace takes the lock when it's free (or already this account's, in which case the row is kept alive without stealing it from a web tab), heartbeats every 90 s while the workspace stays open, and releases on leaving. Web reviewers therefore see "being edited on iPhone" in their LockBanner and don't fight the phone. (3) **Held by someone else → amber advisory strip** above the tab bar: "*alice@… is editing on web — You can keep working; changes from both sides merge on sync.*" The copy preempts the "will I lose my photos?" worry. (4) **Backgrounding:** the heartbeat task freezes with the app; past the 10-minute TTL the server treats the lock as lapsed (web can take it, with the #5.61.1 takeover email), and the next foreground tick re-acquires if free. No release-on-resign — a brief app switch in the field shouldn't hand the lock away. **New code:** `ProjectLockController` (@MainActor @Observable; get→acquire→heartbeat loop, silent error handling — a presence feature must not toast network blips at a field user), four `APIClient` lock methods + wire structs mirroring shared `ProjectLock`/`GetLockResponse`/`LockResponse`/`AcquireLockRequest` field-for-field (wire-only, no manifest impact), and the banner + lifecycle wiring in `ProjectWorkspaceView` (controller starts in `.task(id:)`, stops in `onDisappear`; nil API client → no banner, pre-#6.21.1 behavior). 409 on heartbeat (force-released / taken over) downgrades and re-reads; 409 on acquire surfaces whoever won. **Matrix:** edit-lock row → ✅ both platforms (with the advisory-model note); read-only-viewer row → iOS ❌ by design (only the persistent freeze makes iOS read-only).
