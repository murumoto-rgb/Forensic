* **Summary:** Fix "Failed to decode plan image" red banner on the web floor plan canvas. The component set `img.crossOrigin = "anonymous"` defensively for future canvas-pixel access (e.g. PDF export), but Cloudflare R2 buckets don't have CORS rules configured by default — so the GET on the presigned URL hit the browser's CORS gate and onerror fired. Removing the attribute lets the image load via the standard cross-origin fetch path (same as the photo lightbox uses). Canvas pixel access becomes unavailable but no current feature relies on it; future PDF export from web would need R2 bucket CORS configured first regardless. One-line web fix; no server, no iOS, no schema change.
