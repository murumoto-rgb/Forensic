* **Summary:** Sprint A3 of the AI-tagging completion plan — confidence threshold filter on web. New `useTagConfidenceThreshold()` hook persists to `localStorage` under the same `sitephoto.tagConfidenceThreshold` key iOS uses (cross-codebase portability — same name, separate stores). Default 0.5, identical to iOS. Inline range slider in the `AITagTree` header lets the user dial the threshold up or down; the value live-updates across every `AITagTree` instance in the tab via a custom `sitephoto:thresholdChanged` event (the `storage` event fires cross-tab only). Filter rule: secondary chips with `conf < threshold` are hidden; secondaries with no `tag_confidences` entry are kept (matches iOS's `fallbackTagConfidence = 0.7` discipline where a missing entry is assumed above the 50% default). Hidden count rendered as a small "N hidden" chip next to the slider when any secondary was filtered out, with a tooltip showing the threshold percentage — mirrors the iOS "N hidden" affordance. Primaries are never hidden (iOS pipeline assigns them a 0.99 sentinel; same behaviour here implicitly because the filter only runs on secondaries). Web-only PR. No iOS, server, shared schema, or `manifestSchemaVersion` change.
