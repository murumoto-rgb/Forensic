* **Summary:** Consolidates the Photos-tab filter bar so it stops eating vertical space when a project has many distinct tags. **Before**: three full-width rows of chips — Bucket (one chip per bucket), Tag (one chip per distinct tag across all photos — could be 50+), Use (one per recommended-use). On a 200-photo project with 40 tags that's ~600px of chrome above the photo list. **After**: one wrapping row containing single-select dropdowns (Plan / Placed / Date), toggle chips (Favorites / Needs review / Validation / Measurement), and **multi-select popovers** for Bucket / Tag / Use. Each popover is a single chip-sized button that opens an absolute-positioned overlay with a search input and a scrollable checkbox list (max-height 64). The trigger shows a count badge when any items are selected. Selected items render as small removable "× pill" chips next to each trigger so active state stays visible without expanding the panel. Popovers close on click-outside (mousedown listener bound at window). Search filters the list case-insensitively. iOS uses an inline scrollable carousel for the same task; web's popover pattern is more keyboard- and screen-friendly for desktop. No state shape change in `usePhotoFilters` — only the presentation. No schema / iOS change.
