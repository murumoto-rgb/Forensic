* **Summary:** Phase 3 PR-C-3 — distress add / edit / delete on the web floor-plan canvas. New "Add distress" toggle on the toolbar (mutex with "Unlock pins"), with a kind picker (4 buttons: out-of-plumb door / door-not-latching / crack-in-grade-beam / crack-in-floor). For the three point kinds, click on the canvas to place a single-point mark; for `crackFloor`, drag to draw a freeform polyline (sampled every ~4 plan-pixels for a clean point count). Click an existing distress glyph to open an editor — change kind, edit note, or delete. All mutations stage in a confirm dialog first (mirroring the pin-drag UX from #5.15.1), then route through the existing manifest save loop. New mark IDs are `crypto.randomUUID()` lowercase (matches Postgres `uuid` and iOS `UUID(uuidString:)` case-insensitive decode). Stroke coordinates write as `[[x, y], …]` to match iOS's `CGPoint` Codable encoder so marks round-trip cleanly. Web-only; no iOS, server, shared, or schema change. Closes Phase 3 read+write parity except for camera capture (iOS-only by design), AI tagging (Phase 4), and PDF export (Phase 4).
