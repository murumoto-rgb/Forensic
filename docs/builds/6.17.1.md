* **Summary:** **Web review Wave 3: UX polish (Escape closes modals + Retry on errors + admin discoverability).** Three small wins from the audit, all verified-against-code and trimmed of the items that turned out to be already shipped or out-of-scope. (1) **Escape closes modals.** New `useEscapeKey(active, onEscape)` hook in `web/src/lib/`; wired into the five high-traffic modal sites: `ProjectAIConfig` (confirm-clear, confirm-template, template picker), `ProjectTagSelectionPicker`, `PhotoComparisonView`, `BatchRetagControl`, and the `ProjectAIConfig` "Load template" dropdown. BatchRetagControl gates on `!inFlight` so a live batch can't be Escape-dismissed (the run keeps streaming server-side; a stray keystroke shouldn't trash visible progress). (2) **Retry on photo-thumbnail errors.** `PhotoList`'s error card previously said "Couldn't load thumbnails — <message>" with no recovery — the user had to toggle a filter to force the effect to re-run. Now ships an explicit Retry button that clears the cache's `attempted` set and bumps a nonce in the effect's dep array, re-issuing the batch fetch in place without dropping the rest of the component's state. (3) **Admin-page discoverability from the project list.** The two inline `/admin/tag-library` + `/admin/ai-rules` link buttons (and the missing `/admin/ai-prompt-templates` + `/admin/report-branding`, which were only reachable via Settings) consolidate into one **Team config ▾** dropdown menu in the header. Non-admins see four shared links (tag library, AI rules, prompt templates, report branding); org admins additionally get a **Team & access →** entry styled distinctly (blue, border separator) for `/admin/users`. `getMe()` shapes `isAdmin` on mount — identical pattern to SettingsPage. Outside-click closes the menu; cleaning up after itself if the user navigates away. **Scope notes:** the audit's larger items (extract shared Button component, dark-mode toggle, PhotoPreviewPanel 1,614-line split, modal focus traps) are deferred to Wave 4 — each is a sized refactor on its own. Three other audit items were found already implemented and skipped: PhotoEditorSection rotation already has `title`+aria-label, the freeze-banner UX is excellent, the LockBanner already covers all 7 states correctly. Web typecheck clean.
