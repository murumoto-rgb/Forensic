* **Branch:** claude/server-tolerant-schema-version
* **Merge SHA:** 3ccbec6
* **Summary:** Server stops hard-rejecting on `client manifestSchemaVersion > server`. Hot-fix for "sync failed" toasts on Build #5.6.1 iPhones — likely cause was a transient window where iOS already pushed v2 manifests via TestFlight but Render hadn't yet redeployed the v2 server (the `MANIFEST_SCHEMA_VERSION` import resolved to v1 still). Behaviour is now: log a warning on the server, accept the write. Forward-incompat changes are caught later in the zod parse anyway. Server-only change; no iOS or web rebuild needed.
