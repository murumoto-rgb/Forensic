* **Summary:** Cloud-first **Phase 1, PR 1.1** — the deterministic 3-way manifest merge that lets iOS and web edit the same project concurrently without clobbering each other. Ships in `packages/shared` only; **nothing behavioral changes yet** (the server/web/iOS adopters land in PRs 1.2/1.3/1.4). New `packages/shared/src/merge.ts` exports `mergeManifest(base, server, client) → { merged, report }`: a full-field 3-way merge of the `Project` manifest. **Primitives**: `scalar3` (equal sides → that value; one side moved off base → that side; both moved → field-specific tie-break, recorded in `MergeReport`); `keyedMerge3` (union by stable id, additive on adds, base-aware on deletes with modify-beats-delete so an in-flight edit is never dropped). **Field rules**: user-edited scalars client-wins on tie; `isDeleted`/`stopped` true-wins (destructive intent); timestamps later-wins; `manifestSchemaVersion` max (never downgrade); `photos`+`trashedPhotos` merged as one keyspace by id with residence decided by the merged `trashedAt` (trash wins but the concurrent edit still applies to the now-trashed photo); per-photo `tags`/`pendingSuggestions` base-aware union with 3-way confidence (deliberate lowering honoured, both-changed → max, AI re-tag converges); `tagSelection`/`aiExtraVocabulary` additive deep-union. The merged object is built as a full `Project` literal so adding a manifest field is a compile error here until a merge rule exists (the exhaustiveness guard). **Wire types**: `PutManifestRequest.baseManifest?` (presence flips the server onto the merge path; absent → today's optimistic-concurrency path, so old clients keep working) and `PutManifestResponse.project?` (the merged manifest clients adopt). 67 unit tests cover the determinism laws (`merge(b,X,X)=X`, clean one-sided wins), concurrent additive edits, deletes (incl. modify-beats-delete and soft-delete-vs-edit), tag union/max-confidence, scalar tie-breaks, convergence, and the migration first-sync **superset construction** (with a guard test documenting why `base=server` + a partial client must NOT be used). No manifest-model change → `MANIFEST_SCHEMA_VERSION` and the iOS parity fixtures are untouched.
