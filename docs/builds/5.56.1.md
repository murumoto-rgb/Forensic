Branding sheet's existing "Clear All Branding" button was renamed to "Reset to default" + `arrow.uturn.backward` icon for visual consistency, gained a two-tap confirmation alert + footer explanation, and now toasts on success. Per-project bucket selections already copied from the library are NOT touched by the bucket reset — scoped narrowly the same way the tag library reset is. iOS-only PR. No server / web / shared / supabase / `manifestSchemaVersion` change.

Note: the menu entry for #11 originally implied web admin pages for branding + bucket library would also gain "Restore default" — those pages don't exist on web yet (only tag library + AI rules do), so this PR is iOS-only. A follow-on can add web admin pages for both if office self-serve for branding/buckets becomes a need.
