* **Summary:** Fix the photo grid's N+1 request storm that was 502-ing the Render free tier on Manandhar (~1000 photos). Symptoms were "every photo failed CORS" — but the actual cause was the server returning 502 (which strips CORS headers, making the browser report a CORS failure as a side-effect). Adds `POST /v1/projects/:id/photo-urls` that mints presigned URLs for up to 1000 photos in one round trip; `PhotoGrid` fetches all URLs up front and passes a `photoId → url` map down to each `PhotoThumbnail`. Net result: 1000 server hits → 1. Floor-plan and save requests no longer get starved/502'd while the grid is loading either. Per-photo endpoints (`GET .../thumb`, `GET .../image`) retained for the lightbox and any future single-photo path. Tandem PR: shared + server + web; no iOS change; no schema change (no `manifestSchemaVersion` bump).
