* **Summary:** **Phase 4 — closes the program.** A "Lock project / Finalized" persistent state that an Owner or Admin can toggle to make a project read-only on web AND iOS. Distinct from the transient `project_locks` edit-lock; this is a deliberate persistent state for finalising a report. **Tandem manifest-model change** (`MANIFEST_SCHEMA_VERSION` 2→3): new `Project.isFrozen: boolean` on shared TS (`manifest.ts`), zod (`validation.ts` with `.default(false)` for legacy-payload tolerance), and iOS Swift (`Project.swift` — mirrors the existing `isDeleted` pattern: var with default, included in `init(name:)`, added to `CodingKeys`, `decodeIfPresent ?? false` in `init(from:)` so older saves still decode, `encode(isFrozen, ...)` in `encode(to:)`). Fixtures regenerated via `pnpm parity:regen-fixtures` + version bumped to 3. New merge rule in `merge.ts`: scalar3 with **true-wins** tie-break (freeze is protective intent; never silently un-frozen by a concurrent edit). New parity tests verify both the freeze-true-wins behaviour and the now-67→68 totals. **Web edit gating**: `ProjectWorkspacePage.canEdit = holding && hasWriteAccess && !isFrozen`, plus a `🔒 This project is locked / finalized` banner above the tabs when `project.isFrozen`. **Lock/Unlock toggle** on the Info tab: visible to admin/editor, exempt from `canEdit` (otherwise you'd never unfreeze), wired through `manifest.save`. Locking shows a confirm dialog; unlocking is a direct toggle. **Server enforcement** in `server/src/access.ts` (new `isProjectOwner(userId, projectId)` helper) + `server/src/routes/projects.ts` PUT (both merge and legacy paths): flipping `isFrozen` requires Owner OR Admin (403 `forbidden` for member-editors). Editor saves that leave `isFrozen` unchanged are unaffected. **Old clients keep working**: pre-5.126.1 iOS / web don't send `isFrozen`; zod defaults it to false; server stores false. **Old saves keep decoding**: iOS `decodeIfPresent ?? false` + zod default. No DB migration needed. 68/68 shared tests pass; server + web `pnpm typecheck` (the CI command) clean.
